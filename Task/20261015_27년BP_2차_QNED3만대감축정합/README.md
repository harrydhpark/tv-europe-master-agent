## 3. 세부 엔지니어링 구현 메커니즘

1. **차감 모델 및 기간 선정**:
   - 사용자의 명시적 지침에 따라 98인치 이상 초대형 모델(100", 115" QNED 등 44,866대)은 **절대 수정하지 않고 100% 보존**.
   - 90인치 미만(43, 50, 55, 65, 75, 85, 86인치) QNED 모델에 한하여 차감 대상 선정.
   - 1~4월 초도 물동 및 1분기 가이드를 보호하기 위해 **27년 신모델(M05~M12)의 수량에 비례(Pro-rata)하여 차감**.
2. **최대 잔여법 (Hare-Niemeyer Method) 정수 배분**:
   - 국가별 차감 수량을 M05~M12 각 월별/모델별 셀의 기존 물동량에 비례하여 정확한 정수로 분산 차감.
   - 잔여 정수 차감 시 각 셀의 기존 수량을 초과하지 않도록 캡(`min(ded, qty)`)을 적용하여 **어떠한 셀도 음수가 되지 않도록 무결성 확보**.
3. **Excel COM 무충돌 SaveCopyAs 주입**:
   - `● 261007 27년 BP rawdata_2차_요청_EU회신_backup.xlsb` 안전 백업 자동 생성.
   - `excel.Calculation = -4135` (xlCalculationManual) 설정 후 `BA1403:BL8763` 범위에 2D 블록 일괄 주입.
   - `wb.SaveCopyAs()`를 통해 45.18초 만에 무충돌 원자적 파일 갱신 완료.
