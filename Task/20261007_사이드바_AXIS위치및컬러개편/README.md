## 2. 사용자 요청 사항 및 반영 내역

1. **사이드메뉴 AXIS 가이드 위치 이동**:
   - `AXIS 시스템 소개` 버튼을 기존 Monthly 대시보드 하단에서 **'대시보드 포털 홈' 바로 위(사이드바 최상단)**로 위치 변경.
   - 포털 홈 및 주기별 대시보드 그룹과의 조화를 위해 하단에 1px 구분선(`nav-divider`) 배치.
2. **AXIS 시스템 소개 폰트 색상 및 스타일 개편**:
   - 기존 녹색 텍스트에서 **화이트 볼드체(`color: #ffffff; font-weight: 700;`)**로 변경하여 다크 네이비 사이드바 환경에서 시인성 극대화.
   - 가이드 북 아이콘을 밝은 민트 틸(`#2DD4BF`)로 강조하고 `GUIDE` 배지 유지.
3. **카테고리 테마 컬러 리밸런싱**:
   - **매출/손익 관리**: LG 공식 브랜드 컬러인 **LG Red (`#C40046`, Hover: `#A50034`)**로 전면 적용 (카드 상단 보더, 태그 배지, 타이틀 아이콘, 대시보드열기 버튼, 상단 필터 칩, 사이드바 아코디언 아이콘/카운트 배지).
   - **제품 정보**: 기존 매출/손익 관리의 **에메랄드 틸 (`#0D9488`, Hover: `#0F766E`)**로 전환 적용.
   - **가격 관리**: 앰버 골드 (`#D97706`) 유지.
